# christmas-tree-3d

An interactive 3D Christmas tree where people from anywhere in the world can hang ornaments, share wishes, and leave messages for each other.

Every ornament carries a little story, and every visitor helps the tree grow.

**[🎄 Visit the Christmas Tree](https://christmastree2026.netlify.app/)**

## ✨ Features

- **Interactive 3D Christmas Tree** — A ASCII-style Christmas tree built with Three.js, featuring animated lights, falling snow, and fireworks.
- **Shared Ornaments** — Public ornaments and wishes are synchronized through Firebase, allowing visitors to share the same tree.
- **Messages & Comments** — Read other people's wishes and leave comments on their ornaments.
- **Find My Ornaments** — Locate and revisit ornaments you've previously placed on the tree.
- **Multilingual Experience** — Enjoy the experience in different languages.

Your wish becomes part of a shared Christmas tree. ✨

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| HTML, CSS, JavaScript | Website structure and interactions |
| Three.js | 3D rendering and visual effects |
| Firebase Authentication | Anonymous visitor identification |
| Cloud Firestore | Real-time ornaments and comments |
| Netlify | Website hosting |

## 🔒 Privacy

Visitors can participate anonymously without creating an account.

Public wishes and comments can be viewed by other visitors, while private wish content is intended to be accessible only to its owner.

The **My Ornaments** feature relies on locally stored information and anonymous authentication. Ornaments may not be recoverable after switching devices or clearing browser data.
